LÍNEA DE ÉNFASIS 3 — PLANTILLA WEB
====================================

CONTENIDO
- index.html: Inicio
- temas.html: Temas
- conceptos.html: Conceptos
- casos-practicos.html: Casos prácticos
- proyecto.html: Proyecto - Video Tutorial
- css/estilos.css: estilos compartidos

CÓMO ABRIR
1. Extrae todo el archivo ZIP en una carpeta.
2. Abre index.html con Chrome, Edge, Firefox u otro navegador.
3. Usa el menú horizontal superior para navegar entre las cinco páginas.

IMPORTANTE
- El sitio usa únicamente HTML y CSS; no necesita JavaScript, servidor ni instalación.

- Conserva la carpeta css junto a los archivos HTML para que los estilos se carguen correctamente.

- Los contenidos son una plantilla genérica editable, la cual puede ser editada en según criterios, conocimientos en desarrollo y gustos.

- Para cambiar textos, abre cada archivo HTML con un editor de texto o código.

- El menú o navbar usa enlaces a páginas independientes, por ello encontraras las diferentes fuentes de su diseño en archivos que acompañan el Index.
